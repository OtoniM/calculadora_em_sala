# Calculadora em C++

Uma calculadora de terminal desenvolvida em C++ com diversas operações matemáticas e interface interativa no console.

## Funcionalidades

O programa possui as seguintes operações:

- Soma
- Subtração
- Multiplicação
- Divisão
- Potenciação
- Radiciação
- Fórmula de Bhaskara

Também inclui:

- Validação de entradas
- Tratamento para divisão por zero
- Verificação de radicando negativo
- Temporizadores com `Sleep()`
- Interface formatada no terminal
- Limpeza automática da tela
- Compatibilidade com UTF-8

## Como executar

### 1. Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

### 2. Compile o arquivo

Exemplo usando g++:

```bash
g++ calculadora.cpp -o calculadora
```

### 3. Execute

No Windows:

```bash
calculadora.exe
```
